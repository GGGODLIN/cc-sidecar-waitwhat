# Share copy variants

主檔 `share-copy.txt` 是繁中版。以下是其他語言與長度的備選。

## English

I made cc-sidecar-waitwhat.

When you lose track of what Claude Code is saying, don't ask it — the answer stays in its context, and asking tells it that passage mattered. So this CLI replays the turn through a second model instead. Nothing about it reaches CC's transcript.

## 短版（Discord / 一行）

跟丟 Claude Code 在講什麼？別問它。問它會把那段留在 context 裡。`ww 1` 在旁邊重講，CC 不知道。
